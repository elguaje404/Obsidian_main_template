# Propiedades de la boveda

Actualmente la bóveda tiene 7 propiedades para cada nota.

Aquí se explica la funcionalidad de cada una y que valores puede tener:
```
type: [permanent, resource, project, area, moc, daily, fleeting]
topic: tema principal [salud, programación, psicologia]
tags: palabras clave, "pegatinas" de la nota 
created: [fecha de creación]
updated: [fecha de la ultima actualización]
source: util sobre todo para las type resource, fuente de información [libro/web/video]
status: util para proyectos [paused, completed, closed, active, idea]
```
